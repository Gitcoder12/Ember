# Contributing to Ember

1. Read README.md, ACTIVITY_LOG.md and FEATURE_UPGRADE_PLAN.md.
2. Check open issues/PRs and select one bounded task.
3. Create a feature branch from the current default branch.
4. Add tests for changed behavior, including one failure or boundary case.
5. Update docs and record exact commands/results.
6. Open a PR with evidence, assumptions and limitations.

Do not commit secrets, private information or unlicensed data. Do not report tests or benchmarks that were not run. AI agents may prepare changes and tests, but a human maintainer approves merges and deployments.
