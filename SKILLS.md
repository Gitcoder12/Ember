# Agent Skill Map — Ember

## Domain audit
Inspect supported input formats, domain assumptions, constraints and unsupported cases. Return file-level findings.

## Engineering implementation
Implement one isolated roadmap item and preserve public interfaces where possible.

## Test engineering
Create deterministic fixtures, regression tests and boundary/failure cases. Do not mock away the behavior under test.

## Validation and evidence
Record exact test commands, versions, environment and outcome. Label simulation, synthetic inputs and estimates.

## Documentation and review
Explain user workflows in simple language, then document technical architecture, limits and reproducibility.

Agents cannot autonomously merge, deploy, publish releases or certify engineering results. Human approval is required.
